# Animal Shelter DV2

FIT3179 Data Visualisation 2 project.

## Working title
**Behind the Shelter Doors** — Where Australia’s animals go when they need a second chance.

## Current build
The repository currently contains the first two required advanced map idioms:

1. **Choropleth map** — 2024–25 RSPCA live release rate by state/territory and species.
2. **Proportional symbol map** — 2024–25 RSPCA dogs/cats caseload by state/territory.

## Structure
- `index.html` — single scrolling story page
- `css/style.css` — responsive layout and typography
- `js/embed.js` — Vega-Lite embeds
- `charts/` — human-readable Vega-Lite JSON specifications
- `data/` — chart-ready CSV files

## Data caveat
RSPCA reporting does not represent every Australian shelter and coverage differs by jurisdiction. The visualisation therefore describes outcomes and caseload within the RSPCA network represented by the source data.

## Development
The final submission will remain a single publicly accessible GitHub Pages webpage, with all Vega-Lite specifications available in this repository.
